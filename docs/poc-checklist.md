## Criterio de aprobación

El POC queda aprobado cuando un usuario nuevo puede completar:

```
registrarse
→ elegir karaoke
→ comprar de prueba
→ entrar a Mi Cuenta
→ ver Mis Karaokes
→ descargar
→ cerrar sesión
→ volver a entrar
→ descargar nuevamente
```
